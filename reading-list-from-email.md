## Four data examples still unbuilt

Each names a source no chapter currently uses, checked by grep across all 99.

1. **Polling error against results** — items 43, 1, 22. There is no chapter
   anywhere that puts *published polls* next to *what happened*.
   `poll-simulation` simulates sampling error and `models-markets` scores a
   betting market, but nothing grades a poll. The Wisconsin post-mortem (43) is
   the live case and the Senate Forecast Explorer (1) is a second. **Part II.**

2. **News outlets as the unit** — items 19, 32, 29. Item 19 is peer-reviewed
   (*Political Analysis*) with replication data published, and it places media
   outlets, politicians and the public on one scale from sharing behaviour.
   Part IV has `media-attention`, which is Wikipedia pageviews — an audience
   measure, not an outlet measure. This is the gap the Aug 3 note already
   flagged, and item 19 is the only source on the list that closes it.
   **Part IV.**

3. **The gender gap** — items 25, 33, 38. The phrase does not appear in any
   chapter. This one is cheap: ANES and CES are already in the book, so it is a
   new question on a source already acquired rather than a new acquisition.
   **Part II.**

4. **Military demographics** — item 6. DMDC publishes an annual demographics
   report; nothing in the corpus reads it. Part V is the thinnest part in the
   book (four chapters), and this is state-marshalled data about ordinary
   people, which is exactly its remit. **Part V.**

Items 5, 11, 24, 30, 37, 40 are readings rather than data: they either use a
source already in the book or report a finding without publishing the file
behind it.
