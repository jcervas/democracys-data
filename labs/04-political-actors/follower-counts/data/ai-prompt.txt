The dataset behind this page comes from a source you cannot fetch
today, and no assistant can fetch it for you.

WHY NOT. The numbers are follower counts — X, Instagram and Bluesky —
for all 537 sitting members of Congress, read once on 15 August 2026.
There is no file to download: no platform publishes a list of
congressional follower counts. X sells the API that would answer the
question for $200 a month, and its old free endpoint now returns an
empty page. So the numbers were taken the way a person gets them: a
logged-out browser loaded each public profile, about 900 page loads
over half an hour, and wrote down the number on the screen. Follower
counts move by the minute. The snapshot cannot be reproduced, only
re-taken, and a re-take is a different measurement of a different day.

WHAT EXISTS INSTEAD. One of the three platforms is genuinely open:
Bluesky has a free public API with no key and no account
(public.api.bsky.app), and an assistant can query it for you today.
The handles must come from somewhere else — a volunteer-maintained
roster called unitedstates/congress-legislators covers X and
Instagram, and congressional Bluesky handles can be guessed against
senate.gov and house.gov, domains only the chambers control, so a hit
cannot be the wrong person. A fresh collection built that way is not a
check on this one; it is a new, equally valid snapshot of a moving
number.

WHAT YOU CAN STILL CHECK. These numbers say whether you are holding
the same snapshot this book describes:

  included
- X yielded a count for 490 members, Instagram for 388, Bluesky
  for 135
